# BGM の置き場

ここは**書き出し先**です。中身は `npm run prep:bgm` が作ります。手で置かないでください。

```
raw/bgm/*.mp3        ← ダウンロードした音源をここに置く（git 管理外）
      ↓  npm run prep:bgm
public/audio/bgm/*.mp3   10秒のループ（実ファイルは余白込みで10.4秒）
public/audio/bgm.json    曲の一覧とループ範囲
```

投稿が1つ流れるたびに、この中から1曲が選ばれます。
一巡するまで同じ曲は出ません（`src/core/bgmQueue.ts`）。
一覧が読めないときは Web Audio で合成した仮のBGMに落ちます。

## 動画と同じ10秒で回る

音楽のループは **10.000秒ちょうど**で、動画1本の長さと同じです。
投稿が切り替わると動画は頭出しされるので、そこに音楽も合わせて始めます。
以後、二つのループは揃ったまま進みます。

長さを変えるときは `scripts/prep-bgm.mjs` の `LOOP` と
`scripts/normalize.mjs` の `DURATION` を**必ず両方**揃えてください。
片方だけ変えると、揃えている意味がなくなります。

ずれるのは不穏タイマーが進んだときだけです。BGMの再生速度が最大12%落ちるので、
時間が経つほど音楽が動画から遅れていきます。これは意図した演出です
（`src/audio/engine.ts` の `applyDreadToMusic`）。

## なぜ切り出すのか

配布元の音源はフル尺で1曲5MB近くあり、66曲だと315MBになります。
GitHub Pages に載せるには重すぎます。10秒に切ると合計9.2MBです。

10秒という長さは曲の小節とは合わないので、継ぎ目でリズムがつんのめる曲があります。
本物のショート動画も10秒で音がぶつ切りに戻るので、そのままにしてあります。
気になる曲は `raw/bgm/` から外してください。

## 選ぶときに気をつけること

- **歌なし**。歌詞があると映像の判断の邪魔になります
- **再配布・改変・ゲームへの組み込みが許されているもの**。
  「YouTube で使える」と「Webサイトに組み込んで配布できる」は別の条件です。
  このゲームは GitHub Pages で配信するので、後者が必要です
- 表記が必要な配布元なら `src/config/audio.ts` の `credit` / `url` を直すこと。
  いま入っているのは OpenTracks で、表記は不要とされています
