# BGM の置き場

ここは**書き出し先**です。中身は `npm run prep:bgm` が作ります。手で置かないでください。

```
raw/bgm/*.mp3        ← ダウンロードした音源をここに置く（git 管理外）
      ↓  npm run prep:bgm
public/audio/bgm/*.mp3   45秒 / 112kbps に切り出したもの
public/audio/bgm.json    曲の一覧
```

投稿が1つ流れるたびに、この中から1曲がランダムで選ばれます。
一巡するまで同じ曲は出ません（`src/core/bgmQueue.ts`）。
一覧が読めないときは Web Audio で合成した仮のBGMに落ちます。

## なぜ切り出すのか

動画は10秒なので、曲を最後まで聴くことはまずありません。
配布元の音源はフル尺で1曲5MB近くあり、66曲だと315MBになります。
GitHub Pages に載せるには重すぎるので、頭から使うぶんだけ切り出しています。
切り出し後は合計40MBです。

長さや音質を変えたいときは `scripts/prep-bgm.mjs` の上のほうにある
`DURATION` / `BITRATE` を触ってから、もう一度 `npm run prep:bgm` を走らせてください。

## 選ぶときに気をつけること

- **歌なし**。歌詞があると映像の判断の邪魔になります
- **再配布・改変・ゲームへの組み込みが許されているもの**。
  「YouTube で使える」と「Webサイトに組み込んで配布できる」は別の条件です。
  このゲームは GitHub Pages で配信するので、後者が必要です
- 表記が必要な配布元なら `src/config/audio.ts` の `credit` / `url` を直すこと。
  いま入っているのは OpenTracks で、表記は不要とされています

## 不穏タイマーとの連動

再生中は、不穏タイマーが進むほど

- 再生速度が落ちる（最大 12%）。音程も一緒に下がり、テープが伸びたように聞こえます
- 音量が下がり、環境音が前に出る

という処理が入ります（`src/audio/engine.ts` の `setDread`）。
