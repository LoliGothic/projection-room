# BGM の置き場

ここに音源ファイルを置いて、`src/config/audio.ts` の `BGM.file` にパスを書くと、
そのファイルがループ再生されます。空のままなら Web Audio で合成した仮のBGMが鳴ります。

```ts
export const BGM = {
  file: 'audio/bgm.mp3',
  title: '曲名',
  author: '作者名',
  url: '配布ページのURL',
  license: 'ライセンス表記',
  gain: 0.5,
} as const
```

`title` / `author` / `url` / `license` はクレジット画面にそのまま出ます。
**フリー素材でも表記が必要なものが多いので、必ず埋めてください。**

## 選ぶときに気をつけること

- **ループして不自然にならないもの**。フィードは何周も流れ続けます
- **歌なし**。歌詞があると映像の判断の邪魔になります
- **再配布・改変・ゲームへの組み込みが許されているもの**。
  「YouTube で使える」と「Webサイトに組み込んで配布できる」は別の条件です。
  このゲームは GitHub Pages で配信するので、後者が必要です

## 不穏タイマーとの連動

再生中は、不穏タイマーが進むほど

- 再生速度が落ちる（最大 12%）
- 音量が下がり、環境音が前に出る

という処理が入ります（`src/audio/engine.ts` の `setDread`）。
合成BGMの場合はさらに、音程が半音ぶん下がって濁り、テープが伸びたように波打ちます。
